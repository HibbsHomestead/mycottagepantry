This version supports one flat artwork overlay, numeric rectangular panel calibration, and manual rectangular gangsheet crops. It does not perform background removal, automatic design separation, perspective/fabric warping, gangsheet layout, or production print-file preparation. Gallery saves patch image metadata only and never move stock, edit a BOM, alter costs/prices, post finances, or publish a storefront. Saving edits creates a new revision so earlier mockups remain available. Saved previews are bounded to the source width and 2400px; downloads support up to 6000px and 24 megapixels, with resolution warnings. Sources remain limited to PNG/JPEG/WebP under 5 MB and 40 megapixels.
