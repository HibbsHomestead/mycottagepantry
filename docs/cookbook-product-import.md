# CookBook exports and product links

## CookBook Manager

Recipes → Import → Import from CookBook accepts shared plain text matching the user-supplied “Best Crumble Topping” sample. Paste the text or upload UTF-8 `.txt`. ZIP collections are supported only when every non-directory entry is a supported shared-text recipe. ZIP envelopes were tested using generated fixtures containing the supplied text, not an actual CookBook native ZIP export. No native JSON/XML/proprietary format is claimed supported without a real sample. Individual PDFs remain available through generic Upload a recipe file and its configured extraction provider.

The exact supplied “Best Crumble Topping” sample produces six required ingredients, one optional addition and five ordered instructions under “Crumble topping:”. The source URL stays separate from description; the CookBook footer remains attribution. The “pecans, walnuts and/or oats” choice stays together outside required Pantry matching and costing. The butter and optional-addition ranges remain unknown until reviewed. The sample has no yield, timing, recipe ID or photo; these remain unknown. No photo integration for undocumented CookBook exports is claimed. Native formats and linked-photo handling need a real export containing those fields before an adapter can be verified.

CookBook shared text and generic pasted text now use the same section classifier. Pending drafts can preview a reprocess from the preserved source, retaining valid matches for unchanged original lines. Applying the proposed replacement requires confirmation; approved recipes are never changed by this action. See [Recipe import](recipe-import.md) for review, persistence and repair verification.

Archives have a 5 MB compressed limit, 100 entries, 2 MB per entry, 10 MB combined uncompressed, and 1–10 recipes. Unsafe paths, symlinks, encrypted entries and unsupported files are rejected. Originals remain unchanged in private workspace-scoped Blobs; each draft retains its own source text and URL. Imports use the existing database-backed queue, Pantry matching, conversion checks and atomic idempotent approval. Collection recipes are reviewed and approved individually; bulk approval is unavailable. Skip by cancelling an individual draft. No account connection, passwords, private endpoints or automatic sync are used. The existing account-adapter interface remains reserved for supported future integrations.

## Retailer product links

Add Ingredient and Edit Ingredient share a product-link review component. The authenticated workspace backend fetches public HTTPS pages with the existing DNS validation/pinning, redirect revalidation, timeout and 1 MB download limit. It reads Schema.org Product/Offer JSON-LD through Cheerio; no paid extraction service, retailer API, AI credentials or new configuration is required. This supports accessible pages exposing that data, not every retailer. Login, location, bot-protected and unsupported pages retain manual entry; no bypass or screenshot/pasted-product extractor is implemented.

Only returned values are offered. Product variants/offers require selection when multiple candidates exist. SKU stays separate from barcode. Aggregate low prices and unit-price specifications are not substituted for package prices. Unambiguous physical amounts in titles are flagged for package verification; multipack amounts are not guessed. Unknown currency, prices, allergen statements and contents stay absent. The user chooses fields individually, sees existing values and explicitly approves cost-reference changes. Applying updates only the unsaved form. Existing conversion summaries handle compatible quantities; density is never guessed.

Optional photo import requires approval, uses the same private graphics upload/storage pipeline, validates actual image bytes, and preserves a source reference in asset tags. Remote image downloads share the 1 MB fetch limit. Photo failures leave text usable. Confirm permission to copy source artwork. Source Contains and May contain text remain separate, and applying label suggestions clears reviewed status. Saving uses existing ingredient persistence; searching/applying never receives stock or posts financial records.

## Verification and limitations

The supplied Sam’s Club flour URL was fetched live through the secure backend helper. It returned Member’s Mark Bread & Pizza Flour, 25 lbs., brand, barcode `078742251462` and retailer SKU `13909715756`. No package price was provided; no price was invented. Package quantity 25 lb was parsed from the title for explicit user review. This does not verify checkout price, store availability, or unrestricted future access.

Automated tests cover supplied-text fractions/groups/order/missing yield, supported and unsafe ZIPs, variants, missing barcode and prices, multipack ambiguity, private URLs, selected-field application, cancellation, cost-change approval and photo failure. Existing recipe-import and Pantry tests cover conversion/matching and data behavior. Authenticated end-to-end saving/reopening, durable remote photo copying and visual browser checks were not performed in this run. No real native CookBook export or collection was provided; generated ZIP fixtures are not represented as native export verification.
