Cottage Pantry uses one interface theme across the workspace, Radix components, public pages, account forms, and support controls. The visual defaults live in `src/styles.css`; the existing appearance palette applies the same neutral colors at startup and when a saved theme loads. `src/interface-typography.css` supplies the screen hierarchy and shared control rules.

Use the system sans-serif (`--font-body` and `--font-heading`). Body and form text are 16px; supporting text has a 14px floor. Page titles are 30px/600, section headings 20px/600, and card headings 18px/600. Label artwork, font samples, and printed documents are content and retain their own typography.

Use white cards on #F8FAFC with #111827 text, #475569 supporting text, and light gray dividers. The default primary accent remains Cottage Purple (#5C3A83). Existing user-selected accents and dark mode remain available. Success, warning, error, and information use their semantic foreground/background token pairs. Form boundaries use the stronger `--border-control` token for visibility.

Reuse the existing Radix components in `src/components/ui` and Lucide icons. Standard controls are 44px high, with 8px corners; cards and dialogs use 12px corners and subtle shared shadows. Spacing tokens provide 4, 8, 12, 16, 24, and 32px. Finance now consumes these same tokens instead of a separate cream/olive palette. Mobile finance navigation scrolls within its container; wide registers retain horizontal scrolling.

The browser review uses deterministic demonstration records, intercepts workspace requests, and rejects writes. Run `npx playwright test tests/modern-system.spec.ts --workers=1` with Netlify dev on port 8889. Set `EXTENDED_DESIGN_AUDIT=1` to include additional workspace and public pages. Set `AXE_SCRIPT` to a local axe-core script to include its WCAG text contrast checks. JSON reports and screenshots are saved beside the review index. Automated checks cover the rendered states; they are not certification of every possible user-created label, image, theme, or interaction.
