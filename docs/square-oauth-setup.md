# Square setup

Square platform subscription billing was retired. Its credentials and checkout setup are not prerequisites for Stripe billing.

Customer Square seller sales authorization is a separate, implemented flow whose live readiness remains unverified. Its operator-only configuration, required callback, schema approval gate and release evidence are documented in [Square seller connection readiness](./square-seller-operator-setup.md). Do not ask customers for platform credentials or treat fixture tests as a verified live seller connection.
